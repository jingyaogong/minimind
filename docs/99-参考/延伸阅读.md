## 📄 一、必读论文（与 minimind 结构/算法直接对应）

| 论文 | 与 minimind 的对应 | 推荐理由 |
|---|---|---|
| [Attention is All You Need](https://arxiv.org/abs/1706.03762) | 整个 Transformer 起点 | 必读。minimind 是其 Decoder-Only 简化版 |
| [RoFormer: Enhanced Transformer with Rotary Position Embedding](https://arxiv.org/abs/2104.09864) | RoPE 旋转位置编码 | minimind 的位置编码核心，`model_minimind.py:62-84` |
| [GQA: Training Generalized Multi-Query Transformer Models from Multi-Head Checkpoints](https://arxiv.org/abs/2305.13245) | GQA 分组查询注意力 | minimind q=8/kv=4 即 GQA，省显存关键 |
| [SwiGLU: Receptance Weighted Layer](https://arxiv.org/abs/2002.05202)（兼 GLU 论文） | SwiGLU FFN 激活 | minimind FeedForward 实现依据 |
| [LLaMA: Open and Efficient Foundation Language Models](https://arxiv.org/abs/2302.13971) | RMSNorm + SwiGLU + RoPE 组合开源范本 | 现代开源 LLM 的"配方表" |
| [Qwen3 Technical Report](https://arxiv.org/abs/2505.09388) | minimind-3 结构主线对齐对象 | minimind-3 的设计直接对齐 Qwen3 / Qwen3-MoE |
| [YaRN: Efficient Context Window Extension of Large Language Models](https://arxiv.org/abs/2309.00071) | RoPE 长文本外推 | minimind 推理时 `--inference_rope_scaling` 即 YaRN |
| [DeepSeek-R1](https://arxiv.org/abs/2501.12948) | GRPO 推广、reasoning 蒸馏 | minimind RL 章节与 thinking 设计的重要参考 |
| [MobileLLM: Enhancing Small Language Models for On-Device Use Cases](https://arxiv.org/abs/2402.14905) | 小模型"深窄 vs 矮胖"取舍研究 | minimind dim=768/layers=8 选型的直接依据 |

## 📌 阅读顺序建议

1. **入门级**（先做这些）：跑通 minimind → 看 Karpathy 视频 → 读主 README → 看 3B1B 可视化
2. **进阶级**（理解原理）：读 LLaMA 论文 → 读 Qwen3 技术报告 → 读 RoPE / GQA / SwiGLU 原论文
3. **研究级**（深入 RL）：读 InstructGPT → DPO → GRPO / DeepSeek-R1 → CISPO → Toolformer
4. **扩展级**（多模态/工程）：clone minimind-v / minimind-o → 看 verl / Llama-Factory 的工程实现

> 别忘了：**先跑通再读论文，效率高 10 倍**（见 [HOW_TO_LEARN.md](../HOW_TO_LEARN.md) 学习心法 2）。
