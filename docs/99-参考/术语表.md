## 🧱 一、基础概念

| 术语 | 简释 | 代码位置 |
|---|---|---|
| **Decoder-Only** | 只保留解码器堆叠的 Transformer 结构（GPT/Llama/Qwen 都是），靠自回归逐 token 生成 | `model/model_minimind.py:178`（Block）|
| **Token / Tokenizer** | 文本切分的最小单元；tokenizer 负责文本↔id 映射。minimind 用 6400 词表 | `model/tokenizer_config.json` |
| **BPE（Byte-Pair Encoding）** | 按字节频率合并子词的分词算法，OOV 少 | `trainer/train_tokenizer.py` |
| **ByteLevel** | BPE 在字节级别预处理，避免未定义字符；Qwen/GPT-2 用 | `model/tokenizer_config.json` |
| **Embedding** | 把 token id 查表映射为稠密向量；minimind 用 `nn.Embedding` | `model/model_minimind.py:201` |
| **Cross Entropy（交叉熵）** | 分类常用损失；LLM 里即"预测下一个 token 的负对数似然" | `model/model_minimind.py:252` |
| **BPB（Bits Per Byte）** | 每字节的平均比特数；跨 tokenizer 比 PPL 更公平（README "Tokenizer" 章节提到） | — |
| **Scaling Law** | 模型性能随参数/数据/算力幂律增长的规律；小模型有反常现象 | README "模型配置" 章节 |
| **涌现能力 Emergent Ability** | 模型规模到一定程度后才出现的突跃式能力（如 in-context learning） | — |

## 🏗️ 二、模型结构

| 术语 | 简释 | 代码位置 |
|---|---|---|
| **RMSNorm** | LayerNorm 变体，不减均值只除 RMS，省算力；Llama/Qwen 标配 | `model/model_minimind.py:50` |
| **Pre-Norm vs Post-Norm** | 归一化在残差前 vs 后；Pre-Norm 训练更稳定，现代 LLM 用 | `model/model_minimind.py:188,193` |
| **RoPE（Rotary Position Embedding）** | 旋转位置编码，通过旋转矩阵把位置注入 Q/K，相对位置自然表达 | `model/model_minimind.py:62,80` |
| **YaRN** | RoPE 长文本外推方法，频率缩放让模型支持超训练长度 | `model/model_minimind.py:64-73` |
| **Attention / Self-Attention** | 让每个 token 与序列内所有 token 计算相关性的机制 | `model/model_minimind.py:91-134` |
| **MHA / MQA / GQA** | Multi-Head / Multi-Query / Grouped-Query Attention；GQA 折中显存与效果，minimind 用 q=8/kv=4 | `model/model_minimind.py:100-102` |
| **Flash Attention** | fused attention kernel，PyTorch 2.x 调 `F.scaled_dot_product_attention` | `model/model_minimind.py:125-126` |
| **KV Cache** | 自回归生成时缓存已算 K/V，每步只算新 token；推理快的关键 | `model/model_minimind.py:120-123` |
| **SwiGLU** | 带 gate 的 FFN，3 个矩阵换更强表达力；`Silu(xW_g)⊙xW_u` | `model/model_minimind.py:136-146` |
| **FFN（Feed-Forward Network）** | Transformer 中的两层 MLP；SwiGLU 是其变体 | `model/model_minimind.py:136` |
| **MoE（Mixture of Experts）** | 多个 expert FFN + 路由，每 token 只激活 top-k；总参大激活小 | `model/model_minimind.py:148-176` |
| **aux_loss（负载均衡损失）** | 防 token 全挤一个 expert 的辅助损失，Qwen3-MoE 同设计 | `model/model_minimind.py:171-173` |
| **LayerNorm vs RMSNorm** | LN 减均值+除方差+仿射；RMS 不减均值只除 RMS | `model/model_minimind.py:50` |
| **tie_word_embeddings** | embedding 与 lm_head 共享权重，省参数；minimind 默认 True | `model/model_minimind.py:30,242` |
| **chat_template** | Jinja 模板，把多轮对话/messages 渲染成模型输入串 | `model/tokenizer_config.json`（chat_template 字段）|

## 🎯 三、训练

| 术语 | 简释 | 代码位置 |
|---|---|---|
| **Pretrain（预训练）** | 无监督学语料规律，目标是"高质量词语接龙" | `trainer/train_pretrain.py` |
| **SFT（Supervised Fine-Tuning）** | 用指令-回答对监督微调，让模型学会对话与指令跟随 | `trainer/train_full_sft.py` |
| **LoRA（Low-Rank Adaptation）** | 在权重旁加低秩分支只训新增参数；PEFT 主流；minimind 从 0 实现 | `model/model_lora.py`, `trainer/train_lora.py` |
| **混合精度 AMP** | 训练用 bfloat16 / float16，省显存加速；默认 `dtype=bfloat16` | 各 train_*.py `--dtype` 参数 |
| **Gradient Accumulation** | 小 batch 多次前向再一起反传，等效大 batch | 各 train_*.py `--accumulation_steps` |
| **学习率调度 LR Schedule** | 训练中动态调 lr；minimind 用 cosine 调度（含 warmup） | `trainer/trainer_utils.py:40` |
| **Checkpoint** | 保存的模型/优化器/进度文件，用于续训或评测 | `trainer/trainer_utils.py:63`（`lm_checkpoint`） |
| **断点续训** | 中断后从检查点恢复训练，支持跨 GPU 数量恢复 | `trainer/trainer_utils.py:108-116` |
| **Loss Mask** | 只在 assistant 回答部分计算 loss，prompt 部分置 -100 屏蔽 | `dataset/lm_dataset.py:88`（SFT）/ `:176`（DPO） |
| **知识蒸馏 Distillation** | 学生模型学教师输出；黑盒=硬标签 SFT，白盒=加 KL 拟合分布 | `trainer/train_distillation.py` |
| **DDP（DistributedDataParallel）** | 单机多卡数据并行；`torchrun --nproc_per_node N` 启动 | `trainer/trainer_utils.py:44` |

## 🚀 四、推理

| 术语 | 简释 | 代码位置 |
|---|---|---|
| **generate（自回归生成）** | 逐 token 采样直到 eos 或 max_new_tokens | `model/model_minimind.py:257-288` |
| **temperature** | 控制 softmax 锐度；↑ 更随机，↓ 更确定 | `model/model_minimind.py:267` |
| **top_k** | 只在 logits 最高的 k 个里采样 | `model/model_minimind.py:271-272` |
| **top_p（nucleus sampling）** | 在累计概率达 p 的最小集合里采样 | `model/model_minimind.py:273-277` |
| **repetition_penalty** | 对已出现 token 加惩罚减少重复 | `model/model_minimind.py:268-270` |
| **Adaptive Thinking（自适应思考）** | 推理时按 open_thinking 开关动态切换"是否显式输出思考过程" | `model/tokenizer_config.json` chat_template；`eval_llm.py:45` |
| **Tool Call** | 模型输出结构化工具调用，由外部执行后回填 | chat_template + `eval_toolcall.py` |
| **YaRN 外推** | 推理时 `--inference_rope_scaling` 启用，免训练扩上下文 | `model/model_minimind.py:31-39`；`eval_llm.py:41` |

## 🎮 五、强化学习 / 后训练

| 术语 | 简释 | 代码位置 |
|---|---|---|
| **RLHF** | 基于人类反馈的强化学习；偏好由人类标注，成本高 | README "强化学习"章节 |
| **RLAIF** | 基于 AI 反馈的 RL；奖励来自 RM/规则/环境 | README "强化学习"章节 |
| **Preference Learning（偏好学习）** | 用 chosen/rejected 对训练，让模型偏好"好的" | `trainer/train_dpo.py` |

| **On-Policy vs Off-Policy** | 是否用当前策略实时采样；PPO/GRPO on-policy，DPO off-policy | README "统一视角"章节 |
| **Reward Sparsity（奖励稀疏）** | 小模型通用任务几乎全错，奖励全零无法学习；需稠密连续信号 | README "RLAIF 限制"折叠区 |

## 📚 关键概念速记口诀

- **结构对齐**：RMSNorm + Pre-Norm + RoPE + GQA + SwiGLU + MoE(可选) = Qwen3 风格
- **训练全链**：Pretrain → SFT → (LoRA / Distill) → DPO → PPO/GRPO → Agentic RL
- **推理三件套**：KV cache（快）+ temperature/top_p/top_k（多样性）+ YaRN（长上下文）
- **PO 三组件**：策略项 $f(r_t)$ + 优势项 $g(A_t)$ + 正则项 $h(\text{KL}_t)$，所有 RL 算法都是其变体
