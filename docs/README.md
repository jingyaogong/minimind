> 当前文档**仅对齐 minimind-3 主线**（2026.04 发布，结构对齐 Qwen3 / Qwen3-MoE）。

## 🎯 你将收获什么

读完 + 跟着做完后，你应当能够：

- 🔍 **真正理解** Transformer Decoder-Only 的每一行代码（不是调库）
- 🧠 **从 0 训练**出一个能对话的 64M LLM，单卡 4090 约 2 小时
- ⚙️ **跑通** Pretrain → SFT → LoRA → DPO / GRPO → Agentic RL 全链路
- 🚀 **部署** OpenAI 兼容 API、WebUI、vllm / ollama 推理
- 🛠️ **改造** 模型为自己的垂域助手（医疗、自我认知等）

> 不需要 ML 背景，但需要 Python 基础与一台能跑 PyTorch 的机器（GPU 推荐，CPU 也能慢慢跑）。

| Track | 目标画像 | 时长 | 推荐入口 |
|-------|---------|------|---------|
| 🟢 **T1 速通 Zero** | 想**最快**跑出一个能对话的模型 | ~3h | [02-实战/01-预训练](./02-实战/01-预训练Pretrain.md) |
| 🔵 **T2 系统精读** | 想真正**读懂 LLM 内部** | 1-2 周 | [00-起步/02-代码地图](./00-起步/02-代码地图.md) |

| 🟠 **T4 应用工程** | 想把模型**部署起来用** | 1-2 天 | [04-部署/01-推理服务与评测](./04-部署/01-推理服务与评测.md) |

> 不知道选哪条？选 **T1**，先把模型跑出来再回来。心理学告诉我们：**第一次快速拿到结果**是建立自我效能感的关键。

## 🧭 第一次来？按这三步走

1. **5 分钟**：读 [HOW_TO_LEARN.md](./HOW_TO_LEARN.md)（学习心法 + 工具用法）
2. **15 分钟**：读 [00-起步/02-代码地图](./00-起步/02-代码地图.md)（搞清楚每个文件干嘛）
3. **30 分钟**：按 [00-起步/01-环境准备](./00-起步/01-环境准备.md) 装好环境并跑通 [03-跑通现成模型](./00-起步/03-跑通现成模型.md)

完成上面三步，你就拥有了**第一个能对话的 minimind**。然后挑一条 Track 继续。
