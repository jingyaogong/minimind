# 00-起步 / 03 - 跑通现成模型

> **TL;DR**：下载预训练好的 `minimind-3` 权重，5 分钟跑通 CLI 推理和 WebUI。
> **心理学技巧**：先看到"成品"长啥样，再回头自己训 —— 自我效能感的最快来源。

## ✅ 你将能

- 用现成权重跑通 minimind 对话
- 启动 WebUI 网页聊天界面
- 用 vllm / ollama 等第三方引擎加速推理

---

## 步骤 1：下载权重

> 现成权重是 minimind 作者训好的，**结构与你从 0 训练得到的是完全一样**的，可以用来对照、调试、demo。

国内推荐 modelscope（快）：

```bash
cd /path/to/minimind   # 仓库根目录
modelscope download --model gongjy/minimind-3 --local_dir ./minimind-3
```

国外用 huggingface：
```bash
git clone https://huggingface.co/jingyaogong/minimind-3
```

下载完成后应该有：
```
minimind-3/
├── config.json
├── model.safetensors
├── tokenizer.json
├── tokenizer_config.json
└── ...
```

## 步骤 2：CLI 推理

```bash
cd /path/to/minimind
python eval_llm.py --load_from ./minimind-3
```

启动后看到：
```
[0] 自动测试
[1] 手动输入
```
选 1，输入"你好"或"为什么天空是蓝色的"，回车看模型回复。

✅ **验证**：模型能输出中文回复，不报错。

## 步骤 3：开启思考链（minimind-3 特色）

```bash
python eval_llm.py --load_from ./minimind-3 --open_thinking 1
```

会看到模型在回答前先输出一段思考过程（`` 标签内）。

> minimind-3 把"是否显式思考"下沉到了 chat_template 层，同一个模型用 `open_thinking=0/1` 切换。详见 [03-进阶/03-工具调用与思考](../03-进阶/03-工具调用与思考.md)。

## 步骤 4：启动 WebUI

```bash
# WebUI 脚本在 scripts/ 下，需要权重文件夹也放过去
cp -r minimind-3 scripts/minimind-3
cd scripts && streamlit run web_demo.py
```

浏览器自动打开 `http://localhost:8501`，可以多轮对话、调温度、开思考链。

> ⚠️ WebUI 脚本会自动扫描 `scripts/` 下包含权重文件的子文件夹，**不复制权重进去会报错**。

## 步骤 5：（可选）用 vllm / ollama 加速

适合生产环境，比纯 PyTorch 推理快 5-10 倍。

```bash
# vllm
pip install vllm
vllm serve /path/to/minimind-3 --served-model-name "minimind"

# ollama（需要先导入 GGUF 格式权重，见 scripts/convert_model.py）
ollama run jingyaogong/minimind-3
```

## 步骤 6：（可选）加载 PyTorch 原生权重推理

如果你想用自己训练的 `.pth` 权重（[02-实战](../02-实战/) 完成后会有），用：

```bash
python eval_llm.py --load_from ./model --weight full_sft
# 或对比预训练阶段：
python eval_llm.py --load_from ./model --weight pretrain
```

`--load_from ./model` 表示用 `model/` 下的代码 + `out/` 下的 `.pth` 权重；
`--load_from ./minimind-3` 表示直接加载 transformers 格式权重。

## 步骤 7：（可选）下载数据，为训练做准备

> 如果你打算走 [02-实战](../02-实战/) 训练自己的模型，现在顺便把数据下了。

```bash
cd /path/to/minimind/dataset
# ✨ 最少只需这两个文件就能快速复现 Zero
modelscope download --dataset gongjy/minimind_dataset --local_dir . \
  --include "pretrain_t2t_mini.jsonl" "sft_t2t_mini.jsonl"
```

完整数据集清单：

| 文件 | 大小 | 用途 | 何时下载 |
|---|---|---|---|
| `pretrain_t2t_mini.jsonl` | 1.2GB | 预训练（mini） | ✨ 必下 |
| `sft_t2t_mini.jsonl` | 1.6GB | SFT（mini） | ✨ 必下 |
| `rlaif.jsonl` | 24MB | PPO/GRPO | T3 时下 |
| `dpo.jsonl` | 53MB | DPO | T3 时下 |
| `agent_rl.jsonl` | 86MB | Agentic RL | T3 时下 |
| `agent_rl_math.jsonl` | 18MB | 数学 RL | T3 时下 |
| `pretrain_t2t.jsonl` | 10GB | 预训练（完整） | 想做完整复现时 |
| `sft_t2t.jsonl` | 14GB | SFT（完整） | 想做完整复现时 |

## 🧯 踩坑提示

### Q1：`OSError: Can't load tokenizer`
路径写错或权重没下全。检查 `ls minimind-3/` 是否有 `tokenizer.json`。

### Q2：CLI 输出乱码
终端编码问题，确保 `LANG=zh_CN.UTF-8` 或 `en_US.UTF-8`。

### Q3：WebUI 报错 "找不到模型"
检查 `scripts/` 下是否有放权重的子文件夹，例如 `scripts/minimind-3/`。

### Q4：推理很慢（< 10 tokens/s）
- 没用 GPU：换有 GPU 的机器
- 显存够：加 `--device cuda:0` 强制
- 想再快：换 vllm / ollama

### Q5：`--open_thinking 1` 没有思考输出
mini 数据训出的 Zero 模型思考能力很弱；想看明显思考链需要完整训练 + RLAIF。
