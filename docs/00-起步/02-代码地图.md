## 一、目录结构总览

```
minimind/
├── README.md / README_en.md     ← 项目百科全书（150KB）
├── requirements.txt              ← 依赖清单
├── eval_llm.py                   ← CLI 推理入口（最常用）
│
├── model/                        ← 模型代码（核心）
│   ├── model_minimind.py         ← 🔥 必读：模型结构 288 行
│   ├── model_lora.py             ← LoRA 从 0 实现
│   ├── tokenizer.json            ← BPE + ByteLevel 词表（6400）
│   └── tokenizer_config.json    ← 含 chat_template
│
├── dataset/                      ← 数据加载
│   ├── lm_dataset.py             ← 🔥 必读：Pretrain/SFT/DPO/RLAIF/AgentRL Dataset
│   └── dataset.md                ← 数据说明
│

│   ├── train_pretrain.py         ← 🔥 必读：预训练
│   ├── train_full_sft.py         ← 🔥 必读：SFT
│   ├── train_lora.py             ← LoRA 微调
│   ├── train_dpo.py              ← DPO（RLHF）
│   ├── train_ppo.py              ← PPO（RLAIF，从 0 实现）
│   ├── train_grpo.py             ← GRPO / CISPO
│   ├── train_agent.py            ← Agentic RL（多轮 Tool-Use）

│   ├── train_tokenizer.py        ← 训练 tokenizer（不建议改）
│   ├── rollout_engine.py         ← RL 采样引擎
│   └── trainer_utils.py          ← init_model / lr / ckp / DDP
│
├── scripts/                      ← 推理与服务
│   ├── web_demo.py               ← Streamlit WebUI
│   ├── serve_openai_api.py       ← OpenAI 兼容 API
│   ├── eval_toolcall.py          ← Tool Call 测试

│
├── out/                          ← 训练产出的权重（.pth）

├── dataset/                      ← 训练数据（.jsonl）
├── images/                       ← README 用的图
└── docs/                         ← 你正在读的这套教程 ✨
```

## 二、必读代码（按推荐顺序）

| 顺序 | 文件 | 行数 | 学到什么 |
|---|---|---|---|
| 1 | `model/model_minimind.py` | 288 | RMSNorm / RoPE / GQA / SwiGLU / MoE / Decoder Block / 自实现 generate |
| 2 | `dataset/lm_dataset.py` | 256 | 数据如何变成 input_ids + labels，chat_template 套用 |
| 3 | `trainer/train_pretrain.py` | 172 | 一个完整的训练循环长啥样（含 DDP / AMP / ckp / 续训） |
| 4 | `eval_llm.py` | 94 | 推理入口、TextStreamer、采样参数 |
| 5 | `trainer/train_full_sft.py` | ~250 | SFT 和 Pretrain 的差异（loss mask） |
| 6 | `model/model_lora.py` | ~80 | LoRA 增量分支怎么挂到 Linear 上 |
| 7 | `trainer/trainer_utils.py` | 177 | init_model / lr schedule / SkipBatchSampler / 奖励模型 |

读这 7 个文件加起来不到 1500 行，**你就读懂了一个对齐 Qwen3 的 LLM 全栈实现**。

## 四、文件命名约定（看名字就懂用途）

minimind 用了**统一命名规则**，记住这条规则就能猜文件：

```
train_<阶段>.py        → 训练脚本
eval_<对象>.py         → 测试脚本
serve_<协议>.py        → 服务端
web_demo.py            → WebUI
convert_model.py       → 权重转换
rollout_engine.py     → RL 采样引擎
model_minimind.py      → 模型本体
model_lora.py          → LoRA 包装
lm_dataset.py          → 数据集类
```

权重文件命名也规律：

```
<stage>_<dim>.pth              → 训练产出（如 full_sft_768.pth）
<stage>_<dim>_resume.pth       → 断点续训检查点
lora_<name>_<dim>.pth          → LoRA 增量权重（如 lora_medical_768.pth）
```

## 五、推荐阅读顺序（系统精读路线）

```
1. README.md 前半段（项目介绍、模型结构、数据介绍）
   ↓
2. model/model_minimind.py（逐行读，对照 README 结构图）
   ↓
3. dataset/lm_dataset.py（理解数据如何喂给模型）
   ↓
4. trainer/train_pretrain.py（看一个完整训练循环）
   ↓
5. eval_llm.py（看推理怎么跑）
   ↓
6. trainer/train_full_sft.py（看 SFT 的差异）
   ↓
7. trainer/trainer_utils.py（看 init_model / lr / ckp / DDP）
   ↓
8. model/model_lora.py + trainer/train_lora.py
   ↓
9. （按兴趣）trainer/train_dpo.py / train_ppo.py / train_grpo.py
   ↓
10. scripts/serve_openai_api.py + web_demo.py
```

> 心理学技巧：**首因效应** —— 把这 10 个文件按这个顺序读完，**已经超过 90% 的"调库侠"了**。
