# 00-起步 / 01 - 环境准备

> **TL;DR**：克隆仓库、装依赖、确认 GPU 可用、约定目录。15 分钟搞定。

## ✅ 你将能

- 在本地 / 远程 GPU 机器上跑起 minimind 的 Python 环境
- 知道权重、数据、检查点各自的存放位置
- 验证 CUDA / PyTorch 可用

---

## 步骤 1：克隆仓库

```bash
git clone --depth 1 https://github.com/jingyaogong/minimind
cd minimind
```

> 你可能已经在 `/home/yourname/minimind`（本地）和 `gpu-4090:/data/TJK/learning/minimind`（远程）各有一份。
> 本地适合读代码、改代码、commit；远程适合训练。见 [HOW_TO_LEARN.md](../HOW_TO_LEARN.md) "协同建议"。

## 步骤 2：创建虚拟环境（强烈建议）

```bash
# 用 conda（推荐）
conda create -n minimind python=3.10 -y
conda activate minimind

# 或用 venv
python -m venv .venv && source .venv/bin/activate
```

## 步骤 3：安装 PyTorch

> requirements.txt 里 torch 是注释掉的，因为不同 CUDA 版本对应不同的安装命令。

按你的 CUDA 版本去 https://pytorch.org/ 找命令。例如 CUDA 12.1：

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

CPU only：
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

## 步骤 4：安装其他依赖

```bash
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple
```

> 国内网络：用 modelscope 替代 huggingface_hub，更稳定。

## 步骤 5：验证环境

```bash
python -c "
import torch
print('PyTorch:', torch.__version__)
print('CUDA available:', torch.cuda.is_available())
if torch.cuda.is_available():
    print('GPU:', torch.cuda.get_device_name(0))
    print('显存:', round(torch.cuda.get_device_properties(0).total_memory / 1024**3, 1), 'GB')
"
```

✅ **验证**：你应该看到类似输出
```
PyTorch: 2.6.0+cu121
CUDA available: True
GPU: NVIDIA GeForce RTX 4090
显存: 23.6 GB
```

如果 `CUDA available: False`：
- 检查 `nvidia-smi` 是否能看到卡
- PyTorch 版本和 CUDA 不匹配，重装对应版本
- 没 GPU 也能跑，只是训练慢几十倍

## 步骤 6：约定目录（理解清楚再开干）

minimind 期望的目录约定：

| 目录 | 用途 | 你需要做什么 |
|---|---|---|
| `./dataset/` | 训练数据 | 下载数据放这里 |
| `./out/` | 训练产出的权重 | 自动创建，存 `*.pth` |
| `./checkpoints/` | 断点续训检查点 | 自动创建 |
| `./model/` | 模型代码 + tokenizer | **不要动** |
| `./trainer/` | 训练脚本 | 在这里执行训练命令 |
| `./scripts/` | 推理 / 服务脚本 | 在这里执行推理命令 |
| `./minimind-3/`（可选） | 下载的现成权重 | 用 `modelscope download` 创建 |

> ⚠️ 训练脚本里默认路径都是**相对路径**（如 `../dataset/...`、`../out/...`），所以**必须在 `trainer/` 或 `scripts/` 目录下执行**，别在仓库根目录直接跑。

## 步骤 7：（可选）安装可视化工具 swanlab

```bash
pip install swanlab
swanlab login   # 注册账号，免费
```

训练时加 `--use_wandb` 会自动用 swanlab 记录曲线，浏览器实时查看。

## 🧯 踩坑提示

### Q1：`ImportError: cannot import name X from transformers`
minimind 依赖 transformers 4.57+，requirements 已锁定版本，没装或装错都会报错。

### Q2：`OSError: CUDA out of memory`（训练时）
- 减小 `--batch_size`（默认 32 → 试 8）
- 增大 `--accumulation_steps`（保持有效 batch 不变）
- 缩短 `--max_seq_len`

### Q3：远程 GPU 机器无法用 swanlab
swanlab 在国内可用，无需梯子。如果还是连不上，加 `--use_wandb` 不传值即可关闭。

### Q4：Mac MPS 用户
部分算子 MPS 不支持。能跑 pretrain 和推理，但 DPO/RL 部分可能报错，建议远程 GPU。
